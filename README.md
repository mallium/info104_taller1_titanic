## Getting Started

First, checkout the repository:

```bash
git clone https://github.com/mallium/info104_taller1_titanic.git
```

Then install the app (let the package manager see what the app needs and download the node modules needed)

```bash
npm install
#or
pnpm i
```

(this will create the node_modules folder)

Finally, run the server loading the app

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.js`. The page auto-updates as you edit the file.
